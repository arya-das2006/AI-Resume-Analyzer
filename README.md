# 🚀 AI Resume Analyzer

An AI-powered web application built with Python and Flask to help users analyze resumes and review their skills for job opportunities.

## ✨ Features

- 🔐 User registration and login
- 📄 Resume upload
- 📊 Interactive dashboard and resume score visualization
- 🕘 Resume analysis history
- 📱 Clean, responsive user interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Tools:** VS Code, Git, GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/arya-das2006/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate it on Windows

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

Open this address in your browser:

`http://127.0.0.1:5000`
